# 内部信效度检验报告

## 1. 研究背景
- **数据来源**: 合并自增强特征数据与议题集中度HHI指数
- **样本量**: 21769 条记录
- **研究变量**:
  - 自变量: 发展需求感知、议题集中程度（HHI指数）、合作纵深性指数
  - 因变量: 中非命运共同体认同强度

## 2. 合成指标内部一致性检验

### 2.1 中非命运共同体认同强度
- **构成分量**: 归一化情感强度 (normalized_sentiment) + 社区相似度 (community_similarity)
- **分量间相关系数**: 0.7528
- **Cronbach's α**: 0.8590
- **内部一致性评价**: 良好

### 2.2 合作纵深性指数
- **构成分量**: 长期战略词频百分位 (long_term_percentile) + 多元主体互动百分位 (multi_agent_percentile)
- **分量间相关系数**: -0.0814
- **Cronbach's α**: -0.1772
- **内部一致性评价**: 较差

### 2.3 合作纵深性指数原始分量
- **构成分量**: 长期战略词频 (long_term_word_count) + 多元主体互动 (has_multi_agent_interaction)
- **分量间相关系数**: -0.0143

## 3. 结构效度检验

### 3.1 因子分析结果
- **认同强度因子解释方差比例**: 0.8788
- **合作纵深性因子解释方差比例**: 0.6773

### 3.2 结构效度评估
- 认同强度的结构效度: 良好
- 合作纵深性的结构效度: 一般

## 4. 回归分析结果

### 4.1 模型拟合情况
- **样本量**: 21769
- **R²值**: 0.2861
- **均方误差(MSE)**: 0.0166
- **根均方误差(RMSE)**: 0.1289

### 4.2 标准化回归系数
- development_demand_perception: 0.0744
- issue_concentration: 0.0231
- cooperation_depth_index: -0.0091
- 截距: 0.2123


## 5. 结论与建议

### 5.1 信效度检验结论
1. **内部一致性**: 
   - 中非命运共同体认同强度的内部一致性Cronbach's α: 0.8590，属于良好水平
   - 合作纵深性指数的内部一致性Cronbach's α: -0.1772，属于较差水平

2. **结构效度**: 
   - 认同强度的结构效度: 0.8788，属于良好水平
   - 合作纵深性的结构效度: 0.6773，属于一般水平

3. **回归分析**: 
   - 模型R²值为0.2861，具有较弱的解释力

### 5.2 研究建议
1. **指标优化建议**: 
   - 认同强度指标结构合理，可继续使用
   - 考虑优化合作纵深性指数的构成分量，或调整分量间的权重分配

2. **后续研究方向**: 
   - 深入探讨各分量对合成指标的贡献机制
   - 考虑引入更多控制变量，提高模型解释力
   - 进行细分样本分析，验证指标在不同群体中的稳定性
