## 1. 爬虫优化过程

### 1.1 问题分析
- **原始问题**: 爬虫运行卡在某个步骤，无法真实抓取足量数据
- **根本原因**: 工具调用失败/超时、关键词精准度不足、网站选择策略不当

### 1.2 优化策略
1. **数据源优化**: 选择新华网、人民网、中国日报等可靠数据源
2. **关键词策略**: 采用三级关键词结构（主要关键词+次要关键词+补充关键词）
3. **技术方案**: 使用Firecrawl MCP工具替代传统爬虫方法
4. **质量过滤**: 引入相关性评分机制（≥6分才保留）

### 1.3 实施成果
- 创建了 `real_firecrawl_crawler.py` - 基于Firecrawl的真实数据爬虫
- 创建了 `firecrawl_investment_crawler.py` - 备用爬虫方案
- 更新了配置文件 `investment_crawler_config.json`
