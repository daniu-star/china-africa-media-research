# 非洲媒体论文：本地数据审计工具

## 适用情景
原始新闻太大，不能上传。此工具**只在你的Windows电脑读取数据**，不调用网络、云服务或大模型接口；输出一份小型聚合统计报告，**不包含新闻正文、标题、文章链接、逐条数据、文章ID**。请先审阅报告再分享。

论文当前版本主张：2000–2025年、44个网站、22,646条有效新闻、东非72.26%；需要核查变量构造、情感与认同是否存在计算重叠、区域/年份分布、新闻去重、数据粒度，以及可选的回归系数复核。

## 第一步：安装Python
在Windows命令提示符（CMD）输入 `py -3 --version`，建议Python 3.10或更新。Python 3.9也可以。若找不到`py`或`python`，先安装Python（安装时勾选“Add python.exe to PATH”）。

## 第二步：运行
下载压缩包、解压三个文件至**同一个目录**，双击 `运行数据诊断.bat`。它已经填入你提供的源数据地址：

`C:\Users\13067\Desktop\论文\非洲\demo\清洗数据`

或在解压后的文件夹打开CMD手动运行：

```bat
py -3 africa_audit.py --input "C:\Users\13067\Desktop\论文\非洲\demo\清洗数据"
```

分析文件很多时，CMD会显示读取进度；可按 Ctrl+C 中断。原始文件**只读**，绝不修改或删除。

## 第三步：在哪里取报告
双击bat后，结果会存放在：

`C:\Users\13067\Desktop\论文\非洲\demo\非洲_诊断输出\`

优先只上传：`africa_audit_result.zip`。它包含：

- `audit_report.md`：中文摘要、核心风险与处理建议
- `audit_report.json`：详尽的聚合统计、逐文件清单、变量映射与可选模型输出
- `field_mapping_suggestions.json`：字段自动识别结果及可能混淆的列名

`field_mapping.json`会留在本地作为人工修正映射的模板，不会自动打包上传。若自动识别错误，例如发展指标真实列名叫 `dev_score_v3`，在该文件填写：

```json
{
  "development": "dev_score_v3",
  "identity": "真实认同度列名",
  "emotion": "真实情感强度列名"
}
```

再次运行双击批处理即可；请不要填入不存在的列名。

## 文件类型支持

- Python标准库原生支持：`.csv` `.tsv` `.txt`（文本表） `.jsonl` `.ndjson`，及对应 `.gz` 压缩文件。
- `.xlsx` 需要先在CMD执行：`py -3 -m pip install openpyxl`
- `.parquet` 需要：`py -3 -m pip install pyarrow`
- 如需要自动计算**可选的描述性回归**，执行：`py -3 -m pip install numpy pandas statsmodels`。
- 不能直接读取：`.xls`、`.json`单个大数组、`.zip`数据包、数据库文件（`.db`/`.sqlite`）、非表格的`.txt`。如文件主要是这些格式，把**文件名及格式**发给我，我会补充对应读取器。报告会列出读取失败的文件。

内存保护：逐行读取原始文本、只缓存最多40,000条去文本化的数值/地区/年份数据用于可选回归；对大型语料不会整体加载新闻正文。注意每个文件的完整重复检测维护至多100万条哈希，超限后将明确注明重复检测不完整。

## 首次核查重点
1. 选择的数据结构是不是论文真正的“22,646条有效报道”，还是最初75万条新闻；若不同，切勿直接混合回归。
2. 因变量 `identity` 和 `sentiment` 是否呈现数学嵌套。论文目前定义 `identity = (sentiment+semantic)/2`，而情感又是中介变量，存在指标依赖。
3. 数据是否真包含44家不同媒体、各区域份额和时间分布，与论文一致。
4. 相关系数 `worry__confusion` 是否接近论文的0.969。
5. 如果能识别到各回归变量，报告可附“**关联性诊断回归**”；它不是原论文模型的验证，不是因果中介，也没有Bootstrap CI。

## 未能仅靠此工具回答的问题
- 没有原始词表/训练日志就不能确认292词语种子、PCA载荷、BERT微调真实性和指标效度。
- 语义相似度≠对理念的支持；需要独立人工作为效标重新构建因变量。
- 即便相关和间接效应显著，也不能断定新闻报道导致认同；必须补充分层控制、时间顺序或严谨的识别设计。
- 如果同一文件包含不同处理阶段（原始数据、抽样数据、加工结果）且字段结构完全相同，仍需要在研究报告里解释来源/粒度。工具**不会**自动认为所有文件相加就是论文最终样本。

## 安全与常见故障
- 报告含文件名、字段名、媒体名称及汇总数字；如其中涉及敏感信息，请先自行检查。
- 一切计算均在本地执行，代码**没有**任何网络请求或上传功能。
- Windows路径带中文是支持的，尽量将压缩包解压在路径简单的位置。
- 出现“ModuleNotFoundError: openpyxl/pyarrow”就按上文安装对应依赖。
- 如果文件特别多可在CMD调整 `--max-files 5000`。
- 若运行时仍担心内存：手动运行并添加 `--skip-model --model-sample-cap 2000`。
